28 more stickers in a mix of styles: mostly flat vector, line art, retro badges, paper-cut and doodles, with only a few watercolour ones, so the set isn't all realistic. The graphic and animated stickers are listed first. Each card says its style and how I'll animate it on the site.

How to use this

  1. Click Copy prompt and paste it into ChatGPT. The style and colour rules are already inside every prompt.
  2. Download the result as a PNG with a transparent background, about 1024 × 1024 px or larger.
  3. Save it with the exact file name in the black tag.
  4. Put every image in web/public/images/organize/, then tell me. I'll place and animate them across the pages.
